# task_3

Содержит решения для ДЗ №3 в папке `task_3` (task_3_1..task_3_4).

## Как собрать (PowerShell, g++)

Собрать одну задачу вручную (пример для `task_3_1`):

```powershell
cd "C:\Users\Серафим\Desktop\repository\-2025-1\task_3\task_3_1"
g++ -std=c++17 -O2 -Wall -Wextra -finput-charset=UTF-8 -fexec-charset=UTF-8 -o main.exe main.cpp
.\main.exe
Или упрощенная компиляция:

powershell
g++ main.cpp -o main.exe
Описание файлов:
task_3_1/main.cpp — создание текстового файла books.txt с 5 записями о книгах на английском языке.

task_3_2/main.cpp — чтение данных из файла books.txt и вывод содержимого в консоль.

task_3_3/main.cpp — чтение данных из файла books.txt, изменение авторов, названий и годов выпуска книг с созданием нового файла incorrect_books.txt.

task_3_4/main.cpp — подсчет статистики по файлу (количество строк и слов) с записью результата в файл report.txt.

Примечания:
В каждом исходнике присутствует требуемая шапка с информацией о студенте. Данные: Скворцов Серафим Денисович, группа M10-137БВ-25.

Все программы поддерживают русскую кодировку и корректно ожидают ввода перед закрытием.

Для task_3_2 и task_3_3 требуется предварительно выполнить task_3_1 для создания файла books.txt.

Для task_3_4 требуется создать тестовый файл (например input.txt) для анализа.
